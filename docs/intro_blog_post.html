pg_bio

Bringing Computational Biology to the Database Layer

We are about to hit a wall in structural biology. As models generate billions of protein structures, moving terabytes of data into Python just to run basic spatial searches or homology queries is slow, expensive, and unscalable.

pg_bio is a native PostgreSQL extension written in Rust that brings the compute directly to the data.

1. Vector Homology

Replace slow string alignments with high-dimensional embeddings. pg_bio converts biological sequences into dense vectors, allowing you to instantly find structural and functional twins using Cosine Distance mathematics.

SELECT name, embedding_cosine_distance(
    embedding, get_sequence_embedding('MFEGFERRLVD')
) as distance 
FROM proteins ORDER BY distance ASC LIMIT 3;

2. Sparse Attention Traversal

Protein language models generate massive interaction networks. pg_bio compresses these into native Sparse Attention Maps (CSR format) directly inside the database. Instantly traverse allosteric pathways to pinpoint critical active sites.

SELECT get_top_interacting_residues(attention_data, target := 50, limit := 5)
FROM protein_attention_maps WHERE uniprot_id = '1BAY';

3. Z-Order Spatial Indexing

No more brute-force Pythagorean math across millions of atoms. pg_bio maps 3D atomic coordinates into 1D integers using Morton Coding (Z-Order curves). Extract precise 3D binding pockets using standard B-Tree indexes in milliseconds.

SELECT atom_id, coord FROM protein_atoms
WHERE z_index BETWEEN min_z AND max_z;
